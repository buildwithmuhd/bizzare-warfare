# Bizzare Warfare
A low-poly first-person multiplayer shooter built with Godot 4 .NET and C#.

## Technology
- Godot 4 .NET and compatible .NET SDK
- C#
- Godot Physics and Navigation
- Godot Multiplayer API / proposed ENet LAN transport

## Getting started
1. Install Godot 4 .NET editor and compatible .NET SDK.
2. Clone repository and open project in Godot.
3. Build the C# solution.
4. Run the main scene.

## Development principles
- C# is the primary language.
- Keep gameplay systems modular.
- Enforce host authority for match/combat state.
- Prefer data-driven values.
- Test every major feature.
- Verify licenses for third-party assets.

See `Documentation/` for product, architecture, gameplay, networking, QA and release specifications.
