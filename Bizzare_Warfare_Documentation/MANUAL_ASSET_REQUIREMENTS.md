# Manual asset requirements

No manual game-asset download is currently required to begin the primitive-map FPS prototype.

## Required development dependency

- **Godot Engine – .NET 4.7.2, Windows x86_64**
- Category: game editor with C# support
- Official download page: <https://godotengine.org/download/windows/>
- Reason: the installed standard editor cannot create, build, or run Godot C# scripts. The existing .NET SDK is present.

After extracting the official archive, keep it alongside the current Godot executable or in a dedicated tools directory, and open this project with the `.NET` editor.
