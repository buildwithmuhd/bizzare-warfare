# 12 — UI/UX Specification
## Direction
Minimal, readable, fast, visually consistent with low-poly aesthetic.

## Main menu
Logo, Play/Multiplayer, Settings, Credits, Exit.

## Multiplayer menu
Host Match, Find LAN Matches, Direct IP Connection, Back.

## Lobby
Host, connected players, bot count, map, mode, match config and Start Match. Only host controls authoritative lobby options.

## HUD
Crosshair, health, ammo, timer, score, kill feed, hit indicator and match notifications.

## Pause menu
Resume, Settings, Leave Match. Host leaving should trigger documented session termination.

## Results
Winner, ranking, eliminations, deaths, duration, Rematch and Return to Menu.

## Accessibility
Adjustable sensitivity, windowed/fullscreen, sufficient contrast, keyboard-friendly menus, and no reliance on color alone. Errors should explain corrective action.
